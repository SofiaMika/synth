# Простой синтезатор

Учебный проект на HTML, CSS, JavaScript, Tone.js и Bun. На странице есть два синтезатора с разным регистром, четыре ноты у каждого, настройка формы волны, громкости, расстройки и панорамы. Общие регуляторы управляют фильтром, эхом и громкостью выхода.

## Запуск

В папке проекта выполните:

```bash
bun install
bun run dev
```

Откройте адрес из терминала, обычно `http://localhost:5173`. Для проверки сборки: `bun run build`.

## Управление

- Кликните по ноте мышкой, чтобы включить её. Повторный клик выключает ноту. Можно включить несколько нот сразу.
- Перетаскивайте ползунки и круглые регуляторы мышкой. Круглые регуляторы меняются движением влево и вправо.
- Кнопка «Выключить все ноты» останавливает включённые ноты.
- Кнопка «Сбросить все настройки» останавливает ноты и возвращает исходные значения всех регуляторов.
- Клавиши клавиатуры для игры не используются.

Звук начинает работать после первого клика: браузер не разрешает запускать аудио автоматически.

## Файлы

- `index.html` — разметка панели.
- `src/style.css` — внешний вид.
- `src/main.js` — класс `SynthApp`: кнопки, регуляторы и состояние интерфейса.
- `src/audio-engine.js` — класс `AudioEngine`: синтезаторы Tone.js, эффекты и общий выход.
